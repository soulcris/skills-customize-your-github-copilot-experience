# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a simple Hangman game in Python where a player guesses letters to reveal a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description
Write a Python program that picks a secret word, accepts player guesses, updates the revealed letters, and checks whether the game is won or lost.

#### Requirements
Completed program should:

- randomly choose a word from a predefined list
- display the hidden word as underscores or blanks for unguessed letters
- accept one letter at a time as input from the user
- reveal matching letters in the correct positions
- track incorrect guesses and remaining attempts
- print a clear win or lose message when the game ends

### 🛠️ Improve the User Experience

#### Description
Add a polished game loop with helpful feedback so the player can easily understand the current game state and keep playing smoothly.

#### Requirements
Completed program should:

- prevent repeated guesses from being counted again
- show feedback after each guess, including correct or incorrect outcomes
- display the remaining attempts after each round
- end the game cleanly when the word is solved or attempts are exhausted
- use readable formatting so the output is easy to follow
